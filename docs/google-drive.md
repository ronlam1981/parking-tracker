# Google Drive 備份 — 設定步驟

做一次，之後喺 App 入面㩒一下就備份得。**免費，唔使付費帳號。**

## 你會得到咩

- 一個「泊車記錄備份」資料夾，入面係帶時間嘅 JSON 備份檔
- 備份包埋**全部**：車輛、泊車記錄、入油、保養、文件，**連所有相片**
- 換機／清咗 Safari 資料，喺設定㩒「由 Google Drive 還原」就攞得返

## 權限範圍（重要）

用嘅係 **`drive.file`** 權限：**只掂到呢個 App 自己建立嘅檔案**。
你 Drive 入面其他相片、文件，佢**睇都睇唔到**。呢個係 Google 最窄嗰種 Drive 權限。

## 設定（約 10 分鐘）

### 1. 開一個 Google Cloud 專案

1. 去 https://console.cloud.google.com/
2. 上面揀專案 → **新增專案** → 改個名（例如 `parking-tracker`）→ 建立

### 2. 開啟 Drive API

1. 左邊選單 → **API 和服務** → **程式庫**
2. 搜尋 **Google Drive API** → 揀佢 → **啟用**

### 3. 設定同意畫面

1. **API 和服務** → **OAuth 同意畫面**
2. User Type 揀 **外部** → 建立
3. 應用程式名稱：`泊車記錄`；使用者支援電郵同開發人員電郵填你自己個 Gmail
4. 一路 **儲存並繼續**（範圍嗰頁唔使加嘢）
5. **測試使用者** 嗰頁 → **ADD USERS** → 加你自己個 Gmail ← **唔好漏咗呢步**
6. 儲存

> 留喺「測試中」狀態就夠用，唔使送審。只係測試使用者名單上面嘅帳號可以用，
> 而你就係嗰個人。（測試模式下 token 有效期較短，偶然要重新授權一次。）

### 4. 建立 OAuth 用戶端 ID

1. **API 和服務** → **憑證** → **建立憑證** → **OAuth 用戶端 ID**
2. 應用程式類型：**網頁應用程式**
3. **已授權的 JavaScript 來源** → 新增：
   ```
   https://ronlam1981.github.io
   ```
4. 「已授權的重新導向 URI」**唔使填**
5. 建立 → 抄低個 **用戶端 ID**（`xxxxx.apps.googleusercontent.com`）

### 5. 填入 App

打開泊車記錄 → **設定** → **☁️ Google Drive 備份** → 貼落 **Google Client ID** → 完成。

㩒 **立即備份到 Google Drive**，第一次會彈 Google 登入同授權（會見到「未經驗證的應用程式」
警告，因為你冇送審 —— 㩒「進階」→「繼續前往」即可，呢個 App 係你自己嘅）。

## 自動備份

瀏覽器**唔可以喺背景自己備份**（iOS 完全唔支援網頁背景排程）。所以做法係：
**設定 → 自動備份提醒** 揀週期，夠期之後你一開 App 就會問你要唔要備份，㩒「確定」即備。

## 常見問題

**彈「已封鎖存取權」**
→ 你個 Gmail 未加入「測試使用者」名單（第 3 步第 5 點）。

**彈「未經驗證的應用程式」**
→ 正常，因為冇送審。㩒「進階」→「繼續前往（不安全）」。呢個 App 係你自己寫嘅。

**每次都要重新授權**
→ 測試模式下 token 壽命較短。一日內多數唔使再撳，隔耐咗就要再授權一次。

**備份檔幾大？**
→ 主要睇相片。10 張文件相大約 1–2MB。Drive 免費有 15GB，用極都用唔完。

**想停用**
→ 設定入面將 Client ID 清空即可。已備份嘅檔案留喺你 Drive，唔會刪。
