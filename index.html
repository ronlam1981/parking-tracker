資料備份

喺 Google Cloud Console 開一個免費 OAuth 用戶端（步驟見 repo 內 docs/google-drive.md）。
權限只係 drive.file：只掂到呢個 App 自己建立嘅檔案，睇唔到你 Drive 其他嘢。
備份會存入「泊車記錄備份」資料夾，包埋所有文件同單據相片。

影低入油單，AI 會自動填返入油量、單價、金額同日期。
你嘅 API key 只會存喺 Worker（Secret），唔會出現喺呢個網頁。
留空就淨係影相存底，數要自己填。
